# Soft gloves: motion-only architecture snapshot (October 2026)

**Status: past snapshot.** This code belongs to the motion-only phase of the soft-glove project. It was superseded on 21 October 2026 by a goal reset to a sensorless safe-force-range glove. Do not read it as the current goal or architecture.

**What it is.** The software from the project's implementation folder for the motion-only run, last edited on 16 October 2026. It contains the offline pipeline package (`sg_offline`), command-line scripts for perception, recording, scoring and comparison, tests, and three recording timelines used by `timed_recording.py`.

**What it is not.** The repository holds no research records, instructions, recordings, labels or participant data. Scripts that process recordings expect those inputs, so they will not run as they are. The tests were not run as part of this snapshot.
